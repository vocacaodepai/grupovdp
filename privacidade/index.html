Política de Privacidade — Painel VDP

Última atualização: 21 de setembro de 2026

O Painel VDP é um painel interno e de uso pessoal, usado para acompanhar a evolução de projetos e canais do Grupo V.D.P. Esta página explica que dados o painel acessa através de contas do Google (YouTube) e como esses dados são usados.

Quais dados acessamos

Quando uma conta do Google autoriza este aplicativo, acessamos apenas:

  • Estatísticas públicas de canais do YouTube (inscritos, visualizações, vídeos) via YouTube Data API;
  • Dados de desempenho do YouTube Analytics dos canais autorizados (visualizações, tempo assistido, curtidas, comentários, origem do tráfego, vídeos com melhor desempenho) via YouTube Analytics API — apenas leitura, nunca alteramos nada nos canais.

Não solicitamos acesso a e-mails, contatos, arquivos do Drive ou qualquer outro dado do Google além do descrito acima.

Como os dados são usados

Os números obtidos são exibidos exclusivamente dentro do painel, para acompanhamento interno do Grupo V.D.P. Não vendemos, compartilhamos nem usamos esses dados para publicidade. Valores agregados (como contagem de inscritos ou visualizações) podem aparecer publicados como parte do código do painel, mas nenhuma credencial, token de acesso ou dado de identificação pessoal é armazenado ou exposto publicamente.

Retenção e revogação

Tokens de acesso são usados apenas no momento da busca dos dados e não ficam armazenados de forma permanente. Você pode revogar o acesso deste aplicativo a qualquer momento em myaccount.google.com/permissions.

Compartilhamento com terceiros

Não compartilhamos os dados obtidos com nenhum terceiro. O painel é de uso privado do Grupo V.D.P.
